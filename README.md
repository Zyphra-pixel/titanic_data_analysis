# Titanic Data Analysis

## Overview

A data analysis project exploring passenger survival patterns in the Titanic dataset using **MySQL** and **Power BI**.

The analysis examines how survival and survivor distribution varied across passenger characteristics such as gender, embarkation port, age group, and passenger class.

## Tools

- MySQL
- SQL
- Power BI

## Analysis

The project covers:

- Survivor distribution by gender
- Survivor distribution by embarkation port
- Survival rates across age groups
- Survival rates across passenger classes
- SQL-based data aggregation and comparison
- Interactive Power BI visualizations

## Dashboard

The Power BI dashboard is available in:

`powerbi/titanic_analysis.pbix`

## Report

The complete analysis and findings are available in:

`report/TITANIC DATA ANALYSIS.pdf`

## Dataset

The dataset contains **714 passenger records** and includes variables such as:

- Sex
- Age
- Pclass
- Embarked
- Survived
